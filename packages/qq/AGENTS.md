# AGENTS.md - QQ 子项目

修改 QQ 子项目前，先读根目录 [AGENTS.md](../../AGENTS.md)、[packages/AGENTS.md](../AGENTS.md)、[QQ 开发执行规范](docs/QQ开发执行规范.md)和[QQ 开发日志](docs/QQ开发日志.md)。

- 先确认任务范围，只改请求涉及的内容；不要顺手开发其它模块、重写旧架构或扩大功能范围。
- 每个模块开始前先在开发日志登记范围和检查项；写完、验证通过、文档更新后再打勾。
- 代码注释只用简短中文，只在必要处写一行；不要逐行注释、不要堆长说明、不要用夸张或难懂的词。
- 代码、代码注释、测试数据、用户可见文案和修 bug 的内容不使用表情符号；规划文档、状态表和开发日志可以用于醒目标记。
- 名称使用日常中文。新增代码和文案不使用“频道、账本、债务、遗书、死亡威胁”等内部说法；已有公开接口或协议字段必须保留时，只保留标识本身，并写普通中文说明。
- 阈值、间隔、概率、名单、模型、名字、提示词内容和功能开关放入配置；关键词只用于协议解析、安全校验等无法避免的场景，并补测试。
- 新功能必须完整实现并接入真实主链；不要留下假数据、空壳、静默降级或只有目录没有入口的模块。
- 修改行为时同步更新对应 README、规范或状态文档；不能只改代码不改说明。
- 完成前运行与本模块相符的测试、类型检查和 lint，并把结果写进开发日志。
- 代码、注释和用户文案不出现不符合角色的死亡、自毁、威胁、索取或控制话术；角色名字和身份由正常配置提供。
