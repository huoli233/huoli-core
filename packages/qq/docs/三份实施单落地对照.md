# 三份实施单落地对照

本文对照根目录三份实施文档与当前 Huoli QQ 的实际代码，只记录已经接进主链的能力、明确补过的缺口和仍不做的部分。

## 当前主链

```text
收到消息
→ 去重与附件处理
→ 注意力、模式、身体和自我事实
→ 私聊必回或群聊自主准入
→ DSH 主模型判断
→ mind 记录这一轮怎么接
→ 发送工具输出正文
→ 旁白过滤与失败兜底
→ 连续性、记忆、反思和下一轮
```

没有另起一套 QQ Agent 运行时，也没有把旧版前置等待、随机开口、多层内部模型请求原样搬回来。

发慌不是单独写死的一种表演。来源只可能是最近的互动触发、担心、存在性不安、压力和身体紧绷；提示词只给这些感受，具体由模型结合最近对话判断。低精力、口渴和饥饿只缩短表达，不再允许把“有人直接找你”解释成可以不回。

## 自主开口与插话

| 行为 | 当前判断方式 |
| --- | --- |
| 私聊收到真实消息 | 必须真实回一句，先旁白会重排一次，再失败才用配置短句 |
| 群里有人明确点名、引用、戳一戳 | 直接进入模型判断 |
| 完整自主模式普通群消息 | 全部进入模型判断 |
| 群里没人叫但有人在聊 | 模型按现场决定插话或安静 |
| 群里安静下来 | 达到自主间隔后进入一次“自主时刻” |
| 无聊、好奇、想分享 | 作为素材事实进入提示词，不在代码里掷骰子 |
| 发牢骚、撒娇、想吐槽 | 模型可以自己决定，但不能重复刷屏或用情绪逼人回应 |
| 不想说 | 群里用 `qq_stay_quiet` 记录原因和心里话 |

“自主时刻”不会每个心跳都调用模型。默认 QQ 组合开启主动判断；它只在完整自主模式、群聊或最近活跃私聊没人正在说话、没有正在跑的轮次、身体醒着时放行，并按 `nudgeMs` 限制间隔。独立挂载主动包仍默认关闭。

## 回复构建

每次发送同一个工具调用里同时拿到：

```json
{
  "mind": {
    "move": "reply|short_ack|join_chorus|continue_own_topic|cold_open|observe_share|comfort|defend|repair|task|interject|wait|watch|silent",
    "reason": "为什么现在开口",
    "focus": "最想接住对方哪一点",
    "tone": "情绪和关系姿态",
    "target": "robot|other|uncertain",
    "reading": "这句话在表达什么，是否反讽或转述",
    "impulse": "第一反应",
    "counter": "另一边的反对意见或风险",
    "choice": "最后选择哪一边",
    "inner": "只给自己看的心里话",
    "next": "下次想记得什么"
  },
  "text": "真正发给对方的正文"
}
```

`mind` 不会被发出，也不会额外请求一次模型。`text` 才进入最终正文过滤、QQ 发送和记忆回写。发送形式仍由工具决定：普通消息、引用、连发、打岔更正、表情、语音或合并转发。

## 旧 QQ Agent 的取舍

吸收的行为：

- 先判断要不要开口，再构建正文。
- 心里话只给回复定调，不能原样发出。
- 可以直接回应、插话、续话、安慰、修补、等待或只看。
- 没有具体由头时不为了刷存在感硬开口。

没有搬回的结构：

- 每次回复前强制额外跑一次规划模型。
- 用随机数决定说不说。
- 多层队列互相等待直到错过时机。
- 旧版自己的发送器、数据库、命令系统和第二套角色状态。

## 不做与边界

- 不新建第二套生命状态或情绪状态。
- 不自动发私信、评论或陌生人互动。
- 不用公开动作数量衡量自主性。
- 不把自我叙事覆盖旧记忆。
- 不把内部提示词、情绪数值或激素名称发给聊天对象。
- 不把 B站、贴吧、桌宠、游戏和现实设备塞进当前主链；以后只通过独立工具或插件接入。
