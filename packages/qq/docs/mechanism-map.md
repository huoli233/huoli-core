# 机制对照表

这份表回答一个问题：外面那套陪伴机器人有什么机制，我们这边对应什么、差什么。它只写状态与理由，不写实现细节。

## 对照

| 那边的机制 | 干的事 | 我们这边 | 状态 |
|---|---|---|---|
| token 记账 | 按用量记当日账、零点清零、启动回填 | `qq-balance` | 已补：按 `assistant/message` 的 usage 记一笔，跨天清零，重启读回，折成档位交给身体 |
| 价目表 | 按模型价把用量折成钱 | `qq-balance` 的 `prices` 与 `dailyCost` | 已补：配了价目与一天预算就按钱算档位，没配仍按 token 算；价要自己填，没有内置价 |
| 账单报告 | 把账生成 markdown 给人看 | — | 不做：没有前端，账在 `data/qq-balance.json` 里够查 || 隐私闸门 | 凭证与长号码不进记忆 | `qq-memory/src/redact.ts` | 已补：密钥、Bearer、带标签的口令、手机号、身份证、卡号一律换星号 |
| 记忆容量告警 | 占到上限的百分比提醒 | 健康一行的 `full` / `overflow` | 已补：八成提一句，满了报超，两个阈值可配 |
| 记忆卡 | 每日遗忘整理与容量压缩 | `qq-memory` 的 sweep 与放进 | 已有 |
| 生物状态 | 递质、饥饿、睡眠、经期 | `qq-vitals` | 已有：第 5 章 184 条系数已钉成回归用例 |
| 目的机制 | 从素材提候选、算分、决定说不说 | `qq-proactive` | 部分：候选与闸门都有，打分口径不同，见下 |
| 自主生物钟 | 每 60 秒 tick，自己排下一次醒 | `schedule` 加 `tool-schedule` | 已补：她自己排「过多久再想这件事」，到期把那句话送进自己的会话；进程关着期间到期的不会补发，下次启动不重放 |
| QQ 桥接 | 收发消息 | `qq-channel` | 已有；原先只会发，现在补了三个读工具 |
| 翻记录与成员 | 看群历史、成员、具体那一条 | `qq_read_history` / `qq_read_members` / `qq_read_message` | 已补：只翻群不翻私聊，一次最多三十条消息、两百个成员，图片只留记号；用例在 `qq-channel/tests/read.spec.ts` |
| 表情包 | 按标签挑一张发出去 | `qq_list_stickers` / `qq_send_sticker` | 已补：库是本机一份 JSON，按编号发图，发之前照样过出站体检；用例在 `qq-channel/tests/stickers.spec.ts` |
| 戳一戳 | 轻轻戳一下群里的某个人 | `qq_send_poke` | 已补：`pokeEnabled` 默认关，私聊一律不戳 |
| 语音 | 挑一段语音发出去 | `qq_list_voices` / `qq_send_voice` | 已补：库是本机一份 JSON，按编号发一段录音；用例在 `qq-channel/tests/voices.spec.ts` |
| 引用回复 | 引用着某一条回一句 | `qq_reply` | 已补：引用段加正文两段一起发 |
| 连接状态 | 连没连上、重连几次 | `qq_channel_status` | 已补：只报事实 |
| 连发 | 一口气说几句短话 | `qq_send_burst` | 已补：按换行拆，最多六句，每句之间留空，每句都过体检；用例在 `qq-channel/tests/burst-slang.spec.ts` |
| 学黑话 | 从群里学词并记住 | `qq_slang_query` / `qq_slang_submit` | 已补：词表是本机一份 JSON，同一词只记一次；只记词与意思，不记整段对话 |
| 撤回与改口 | 说错了撤回来、补一句更正 | `qq_recent_sends` / `qq_unsend` / `qq_correct` | 已补：只撤自己刚发的，改口会顺手记进自我层错题本；用例在 `qq-channel/tests/correct.spec.ts` |
| 私密事件 | 自己做了不想让人知道的事 | `memory_append` 的 `layer: private` 加 `secret: true` | 已补：原先 `secret` 没人写得进去，那段紧绷感点不着；现在只由模型自己声明，代码不推断，写进去后半小时内群里会收紧一点 |
| 打错字与撤回重发 | 岔一个字、拼音没打完、撤回来再发 | `qq_send_messy` | 已补：收结构化步骤（每步自己声明 kind 与正文），最多八步，只撤自己这一串刚发的；字由模型自己写，代码不改字、不生成错字、不靠中文词面猜动作；用例在 `qq-channel/tests/messy.spec.ts` |
| 短句口头禅谚语 | 学群里怎么说话 | `qq_saying_query` / `qq_saying_submit` | 已补：库是本机一份 JSON，同一句只记一次，只给语料不替她决定用不用 |
| 列库这件事 | 从表情、语音、词、说法里挑一个 | 四个 `qq_list_*` / `qq_*_query` | 已改：只把整份库列出来，不按标签或字串替模型找，选哪个由模型自己判 |
| 角色存档 | 人格快照与回滚 | `qq-self` 的 `persona.md` 与版本 | 已补：人格是文件，启动存一版，改坏了能盖回去 |
| 人格卡拆分 | 一次模型调用把人格卡拆四层 | — | 不做：人格是我们自己写的，没有「导入别人的人格卡」这一步 |
| 跨平台身份对齐 | QQ 与别的平台认同一个人 | — | 不适用：只有一个平台 |
| 先回一句 | 收到消息先回「在的」再想 | — | 不做：每条都先回一句会变成刷屏，回不回由她判断 |
| 打字延迟 | 连发几条时每条之间留点间隔 | `qq-channel` 的 `sendGapMs` | 已补：配了它就按上一条加间隔拒一次，让她隔一会儿再说；默认 0 不拦 |
| 学黑话 | 从群聊里学词并记住 | 记忆与技能 | 不做成独立机制：要用就由她自己记进记忆或写成技能 |
| 管理员身份 | 指定的号能管家 | — | 没有：能做什么由她手上的工具决定，没有「命令」与「闲聊」之分 |
| 自更新 | 拉新版本并替换自身 | — | 不适用：用 git 管 |
| 设置页快照 | 给网页只读的额度与自动化快照 | — | 不适用：界面按方案甲已拆走 |

## 对照的来源

那边的机制清单取自它自己的 `config.example.json`：26 个顶层键就是它的功能目录，比按模块名猜全。少数字段不在配置里（比如控制台、桥接），按模块补进来的。

## 两处故意不同

**打分口径。** 那边给每个候选算置信度、价值、紧迫度、风险再排序；我们把候选与现场交给模型，由它决定说不说。理由是这一层早先定过「判断权归模型，不要用代码阈值替她决定」。所以这不是缺口，是选定的做法。

**隐私边界。** 那边允许跨平台搬运内容（有闸门看着）；我们只有本机，记忆正文不出本机，向量编码也只在本地做。
