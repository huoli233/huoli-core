# 机制对照表

这份表回答一个问题：外面那套陪伴机器人有什么机制，我们这边对应什么、差什么。它只写状态与理由，不写实现细节。

## 对照

| 那边的机制 | 干的事 | 我们这边 | 状态 |
|---|---|---|---|
| token 记账 | 按用量记当日账、零点清零、启动回填 | `qq-balance` | 已补：按 `assistant/message` 的 usage 记一笔，跨天清零，重启读回，折成档位交给身体 |
| 价目表 | 按模型价把用量折成钱 | `qq-balance` 的 `prices` 与 `dailyCost` | 已补：配了价目与一天预算就按钱算档位，没配仍按 token 算；价要自己填，没有内置价 |
| 账单报告 | 把账生成 markdown 给人看 | — | 不做：没有前端，账在 `data/qq-balance.json` 里够查 || 隐私闸门 | 凭证与长号码不进记忆 | `qq-memory/src/redact.ts` | 已补：密钥、Bearer、带标签的口令、手机号、身份证、卡号一律换星号 |
| 记忆容量告警 | 占到上限的百分比提醒 | 健康一行的 `full` / `overflow` | 已补：八成提一句，满了报超，两个阈值可配 |
| 记忆卡 | 每日遗忘整理与容量压缩 | `qq-memory` 的 sweep 与放进 | 已有 |
| 生物状态 | 递质、饥饿、睡眠、经期 | `qq-vitals` | 已有：第 5 章 184 条系数已钉成回归用例 |
| 目的机制 | 从素材提候选、算分、决定说不说 | `qq-proactive` | 部分：候选与闸门都有，打分口径不同，见下 |
| 自主生物钟 | 每 60 秒 tick，自己排下一次醒 | `schedule` 加 `tool-schedule` | 已补：她自己排「过多久再想这件事」，到期把那句话送进自己的会话；进程关着期间到期的不会补发，下次启动不重放 |
| QQ 桥接 | 收发消息 | `qq-channel` | 已有 |
| 角色存档 | 人格快照与回滚 | `qq-self` 的 `persona.md` 与版本 | 已补：人格是文件，启动存一版，改坏了能盖回去 |
| 人格卡拆分 | 一次模型调用把人格卡拆四层 | — | 不做：人格是我们自己写的，没有「导入别人的人格卡」这一步 |
| 跨平台身份对齐 | QQ 与别的平台认同一个人 | — | 不适用：只有一个平台 |
| 自更新 | 拉新版本并替换自身 | — | 不适用：用 git 管 |
| 设置页快照 | 给网页只读的额度与自动化快照 | — | 不适用：界面按方案甲已拆走 |

## 两处故意不同

**打分口径。** 那边给每个候选算置信度、价值、紧迫度、风险再排序；我们把候选与现场交给模型，由它决定说不说。理由是这一层早先定过「判断权归模型，不要用代码阈值替她决定」。所以这不是缺口，是选定的做法。

**隐私边界。** 那边允许跨平台搬运内容（有闸门看着）；我们只有本机，记忆正文不出本机，向量编码也只在本地做。
